# Matemática Aplicada 2024 - FP-UNA

Repositorio de proyectos finales del curso Matemática Aplicada 2024 de la Facultad Politécnica, Universidad Nacional de Asunción.

## Rol del mantenedor

Marcos Villagra diseñó y mantuvo la estructura del repositorio del curso, las pautas de entrega y el flujo de recepción de proyectos. Los proyectos dentro de `proyectos/` son entregas de estudiantes y deben atribuirse a los autores indicados en cada carpeta o entrega.

## Organización

- `proyectos/`: espacio para las entregas finales de los estudiantes.
- `readme.md`: descripción general del repositorio del curso.

## Nota para revisores

Este repositorio muestra trabajo de docencia, mentoría y coordinación académica. No debe leerse como una única aplicación de producción ni como código escrito íntegramente por el mantenedor.
